# AgentTrace v0.3.1

This patch updates the optional NativeRelay integration for the stable NativeRelay 0.4.x line.

## Changes

- Accept NativeRelay versions `>=0.3.0` and `<0.5.0`; NativeRelay 0.4.0 is now recognized as compatible.
- Add regression coverage proving 0.4.0 is compatible and 0.5.0 is outside the tested range.
- Update the NativeRelay integration guide and README for the Windows collector introduced in NativeRelay 0.4.x.
- Document Windows WMI process monitoring with Toolhelp polling fallback, scoped filesystem notifications, and the unsupported file-open event.
- Keep NativeRelay optional and independently installed; AgentTrace does not install Python packages.
- Update the integration workflow to install the stable `nativerelay==0.4.0` package from PyPI and retire the merged feature-branch trigger.

## Installation

```bash
npm install -g @coachlogic/agenttrace
python -m pip install nativerelay==0.4.0
agenttrace watch --native-relay
```

NativeRelay is optional. AgentTrace's built-in process discovery works without it.

## Validation

The release workflow runs the Rust test suite and builds the supported Windows, macOS, and Linux binaries. The NativeRelay integration workflow installs NativeRelay 0.4.0 from PyPI and verifies live Windows process and scoped file observations.
